# Структура монорепозитория

Управление зависимостями — `uv` workspace. Единый lock-файл `uv.lock` и общее виртуальное окружение `.venv` в корне; каждый сервис при этом остаётся самостоятельным пакетом со своим набором зависимостей.

## Каталоги

| Путь | Пакет | Назначение |
| --- | --- | --- |
| `services/aggregator` | `hackneft_aggregator` | Сбор и преобразование данных датчиков и внешних источников |
| `services/platform` | `hackneft_platform` | База данных, пользовательский интерфейс, обработка событий |
| `services/ai` | `hackneft_ai` | Управление и запуск агентов |
| `libs/common` | `hackneft_common` | Код, разделяемый между сервисами: модели данных, конфигурация, служебные утилиты |
| `docs` | — | Постановка задачи и проектная документация |

## Правила зависимостей

Сервисы не импортируют друг друга. Общий код выносится в `libs/common`, что исключает циклические зависимости между сервисами. Библиотека подключается через `[tool.uv.sources]` с `workspace = true` и устанавливается в режиме редактируемой установки, поэтому её правки видны во всех сервисах без переустановки.

Взаимодействие сервисов между собой строится через сетевые границы, а не через импорт пакетов.

## Раскладка внутри пакета

```
services/<сервис>/
├── pyproject.toml
├── src/<пакет>/
└── tests/
```

## Команды

Установка окружения для всего репозитория:

```
uv sync
```

Запуск команды в контексте конкретного пакета:

```
uv run --package hackneft-platform <команда>
```

Добавление зависимости в конкретный сервис:

```
uv add --package hackneft-aggregator <пакет>
```

Проверки:

```
uv run ruff check .
uv run mypy .
uv run pytest
```
