# HackNeft

HackNeft — прототип советчика для оператора производства дизельного топлива.

## Компоненты системы

**Агрегатор — симуляция данных.** Воспроизводит исторические измерения в выбранном темпе, чтобы можно было повторить ситуацию и наблюдать реакцию системы по мере поступления данных.



**Платформа — рабочее место оператора.** Показывает состояние установки, фиксирует поводы для пересмотра режима и выводит рекомендации. Оператор видит события и советы в одном интерфейсе.

**ИИ-сервис — среда для агентов.** Позволяет настраивать и запускать разных агентов, вести их сессии и сохранять результаты. Советник с агентами защиты и производства — один из сценариев его использования в этом кейсе.

Три части разделяют воспроизведение данных, работу оператора и выполнение агентов. Платформа связывает их в единый процесс: от нового измерения до совета оператору.

## Принцип работы

Агрегатор отправляет показания на платформу. Платформа сохраняет их и создаёт события, когда данные указывают на изменение качества топлива, режима установки или достоверности измерений. Некоторые события становятся поводом для запуска советника; платформа объединяет причины и передаёт ему текущие показания вместе с недавней историей.

Советник последовательно запускает двух субагентов. **Агент защиты** оценивает риск нарушения нормы по сере и ограничения для изменения режима. **Агент производства** с учётом вывода защиты рассматривает, есть ли основания улучшить режим. Затем советник сопоставляет их выводы и формирует короткий ответ оператору: сохранить режим, проверить ситуацию или предложить изменение. Субагенты получают данные запуска и при необходимости могут самостоятельно запросить дополнительные показания у платформы.

> Пока советник работает, платформа переводит агрегатор в режим реального времени: одна минута симуляции соответствует одной минуте реального времени. После завершения советника агрегатор возвращается к заданному темпу.

## Запуск и настройка

1. Всё решение поднимается одним файлом [compose.hub.yaml](compose.hub.yaml) из готовых образов Docker Hub. Исходный код, сборка и предварительная настройка не нужны: данные телеметрии и качества встроены в образ агрегатора. Скачайте файл и выполните в его каталоге:

   ```bash
   docker compose -f compose.hub.yaml up -d
   ```

   Docker Compose загрузит образы и запустит все три сервиса: агрегатор, платформу и ИИ-сервис. Чтобы собрать образы из исходников, выполните из корня репозитория `docker compose up --build`; в этом случае агрегатору нужен каталог с подготовленными данными, по умолчанию `../data`, другой путь задаётся через `HACKNEFT_DATA_DIR`.
2. У каждого запущенного сервиса есть веб-интерфейс: [платформа](http://localhost:8000), [ИИ-сервис](http://localhost:8100) и [агрегатор](http://localhost:8200).
3. В ИИ-сервисе на вкладке «Провайдеры» настройте подключение к локальному OpenAI-совместимому серверу моделей. Если сервер моделей работает на том же компьютере, укажите его адрес через `host.docker.internal`, поскольку ИИ-сервис запущен в контейнере. Затем на вкладке «Модели» добавьте модель с поддержкой вызова инструментов и выберите её моделью по умолчанию. Провайдер Yandex AI Studio использовался для тестов.
