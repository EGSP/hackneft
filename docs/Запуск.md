# Запуск приложения из готовых образов

Инструкция для компьютера, на котором установлен только Docker (сборка не требуется —
образы `p0lluxstar/hackneft-*` уже собраны и опубликованы на Docker Hub).

## Требования

- Docker Desktop с поддержкой Docker Compose.

## Шаги

1. Скопировать на компьютер два файла из репозитория:
   - `compose.yaml`
   - `.env.example`

2. Создать `.env` рядом с `compose.yaml`:

   ```
   cp .env.example .env
   ```

   и указать в нём путь к папке с файлами телеметрии (`avt_tags.csv`, `242000_tags.csv`)
   на этом компьютере:

   ```
   HACKNEFT_DATA_DIR=C:\путь\к\data
   ```

   Путь обязательно должен начинаться с `./`, `../` или быть абсолютным (`C:\...` или
   `/...`). Значение без разделителя пути, например `data`, Compose воспринимает не как
   путь на диске, а как имя именованного volume, и падает с ошибкой
   `invalid compose project` («refers to undefined volume»).

3. Положить файлы телеметрии в указанную папку. Если оставить значение по умолчанию
   (`../data`) — положить их в папку `data` на уровень выше `compose.yaml`. Если `data`
   лежит в той же папке, что и `compose.yaml`, — указать `HACKNEFT_DATA_DIR=./data`.

4. (Опционально) Настроить сами сервисы, если нужны нестандартные значения — по образцу
   `services/ai/.env.example` и `services/aggregator/.env.example`: создать
   `services/ai/.env` и `services/aggregator/.env` рядом с `compose.yaml`, сохранив
   структуру подпапок.

5. Запустить:

   ```
   docker compose up
   ```

   Docker скачает три готовых образа с Docker Hub — сборка не потребуется.

6. Открыть в браузере:
   - Платформа (веб-интерфейс с графиком серы) — http://localhost:8000
   - Агрегатор (управление симуляцией потока) — http://localhost:8200
   - ИИ-сервис — http://localhost:8100

7. Запустить симуляцию потока данных на странице агрегатора
   (http://localhost:8200) кнопкой resume/старт — по умолчанию агрегатор стартует на
   паузе, и без этого шага данные не польются на платформу.
