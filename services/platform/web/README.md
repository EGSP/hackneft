# Веб-интерфейс платформы

Vite, React и Ant Design (светлая тема). Графики построены на ECharts.

## Устройство

| Путь | Назначение |
| --- | --- |
| `src/App.tsx` | Раскладка со списком вкладок слева и маршрутизация страниц |
| `src/pages/Dashboard.tsx` | Главная: два ряда серы, выбор периода, подписка на поток событий |
| `src/pages/Synonyms.tsx` | Справочник синонимов: просмотр, добавление, удаление |
| `src/components/SulfurChart.tsx` | Совмещённый график ПАК и ЛИМС с нормой и прокруткой |
| `src/hooks/useSensorStream.ts` | Подписка на `/api/stream` (SSE) |
| `src/api.ts` | Обращения к API платформы |

## Сборка и разработка

Собранный интерфейс складывается в `../src/hackneft_platform/static` и отдаётся оттуда
самим FastAPI: отдельного веб-сервера в рабочем контуре нет, Node нужен только на время
сборки. Каталог статики пересоздаётся сборкой и в репозитории не хранится.

```
npm install
npm run build
```

В разработке запускаются два процесса: `uvicorn` на порту 8000 и сервер Vite на 5173.
Второй перенаправляет обращения к `/api` на первый, поэтому источник для браузера остаётся
один и настраивать CORS на стороне FastAPI не требуется.

```
npm run dev
```

## Используемые эндпоинты

| Эндпоинт | Назначение |
| --- | --- |
| `GET /api/sulfur/settings` | Коды рядов ПАК и ЛИМС и норма содержания серы |
| `GET /api/sensor-data/view` | Выборка за период по нескольким именам датчиков сразу |
| `GET /api/stream` | Поток новых показаний серы (SSE) |
| `GET/POST/DELETE /api/sensor-names` | Справочник синонимов |

## Ограничение

Поток событий хранит подписчиков в памяти процесса, поэтому платформа обязана работать
в один рабочий процесс `uvicorn`. При нескольких процессах показание, принятое одним из
них, до вкладок, обслуживаемых остальными, не дойдёт, и между процессами потребуется
посредник.
